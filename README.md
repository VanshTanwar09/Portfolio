# Vansh Tanwar - Portfolio

A premium futuristic developer portfolio built with React, Vite, and modern web technologies.

## 🚀 Features

- **Multi-page Portfolio**: Home, About, Projects, and Contact pages
- **Dark/Light Theme**: Cyber aesthetic with black + neon orange theme
- **Responsive Design**: Fully responsive across all devices
- **Smooth Animations**: Framer Motion and GSAP powered animations
- **AI Assistant**: Interactive portfolio assistant with local data
- **Modern Tech Stack**: React + Vite + Tailwind CSS + TypeScript

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, GSAP, ScrollTrigger
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Smooth Scrolling**: Lenis

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/vanshtanwar/portfolio.git
cd portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 🎨 Design Features

- **Cyber Aesthetic**: Black background with neon orange accents
- **Glassmorphism**: Modern card designs with backdrop blur
- **Hover Effects**: Premium interactions with glow, tilt, and scale
- **Smooth Transitions**: Hardware-accelerated animations
- **Responsive Layout**: Mobile-first design approach

## 📱 Pages

1. **Home**: Cinematic hero section with animated text and social links
2. **About**: Skills, experience timeline, and certifications
3. **Projects**: Filterable project grid with hover interactions
4. **Contact**: Contact form, social links, and availability status

## 🤖 AI Assistant

The portfolio includes an AI assistant that can answer questions about:
- Vansh's background and skills
- Project details and technologies
- Contact information and availability
